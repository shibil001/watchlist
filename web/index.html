Install help

Mac

Open the .dmg and drag Watchlist to Applications. The first time, right-click the app and choose Open.

Windows

There is nothing to install: save the file somewhere you like and double-click it. To pin it, right-click it and choose Pin to taskbar. If Windows says it protected your PC, choose More info, then Run anyway.

Phone

Android: tap Download for Android. If your browser warns that the file can harm your device, choose Download anyway. Then open the file and allow Install unknown apps for your browser when asked. If Play Protect shows a notice, choose Install anyway. iPhone: open the online version, then Share → Add to Home Screen.
